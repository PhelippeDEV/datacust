# DataCust

**Plataforma de governança, qualidade e rastreabilidade de dados.**

> Em desenvolvimento, Sprint 1 de 8. Estou construindo em público e registrando cada etapa em `docs/diario.md`.

## O que é

O DataCust é uma plataforma web que centraliza o catálogo, a classificação, a qualidade e a linhagem dos dados de uma organização. Ele simula uma solução empresarial usando uma empresa fictícia de logística e comércio exterior, com dados 100% fictícios.

## Problema que resolve

Dados espalhados em planilhas e sistemas, duplicados, incompletos, sem dono e sem documentação. O DataCust reúne esses controles em um só lugar.

## Módulos

- **Data Catalog:** ativos, tabelas, campos e responsáveis.
- **Data Classification:** níveis de confidencialidade e dados pessoais (LGPD).
- **Data Quality:** validações automáticas em CSV e Excel, com nota por dimensão.
- **Data Lineage:** origem, transformações e destino dos dados.
- **Governance Dashboard:** indicadores no Power BI.

## Tecnologias planejadas

Python, FastAPI, PostgreSQL, Pandas, HTML/CSS/JavaScript, Power BI, Docker e Docker Compose.
